
# FreshDeal - Smart Near-Expiry Discount Manager

## Project Overview
FreshDeal is a Python terminal application that helps
retailers monitor product expiry dates and simulate
discounts to help manage potential food and product waste.

## Features
- Add and view inventory products
- Monitor expired and soon-to-expire products
- Simulate discounts and calculate potential revenue
- Calculate inventory value
- Search for products
- Replenish product stock
- Export inventory reports to CSV
- Save inventory data using JSON

## Technologies Used
- Python
- Git
- GitHub
- JSON
- CSV

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python main.py

## Data Storage
The application creates products.json to save inventory
and inventory_report.csv to export inventory reports.

## Academic Purpose
This project demonstrates Python programming,
file handling, date processing, validation,
and version control using Git and GitHub.
